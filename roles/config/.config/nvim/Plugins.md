# Neovim Plugins

Plugins installed by this configuration via `vim.pack.add(...)`.

## Themes

- [oc-2.nvim](https://github.com/0xleodevv/oc-2.nvim): OC-2 color scheme.
- [catppuccin](https://github.com/catppuccin/nvim): Soothing pastel color scheme.
- [nightfox.nvim](https://github.com/EdenEast/nightfox.nvim): Collection of dark and light color schemes.
- [tokyonight.nvim](https://github.com/folke/tokyonight.nvim): Clean, dark Tokyo Night color scheme.
- [dracula/vim](https://github.com/dracula/vim): Dracula color scheme.
- [onedark.nvim](https://github.com/navarasu/onedark.nvim): Atom-inspired One Dark color scheme.
- [github-monochrome.nvim](https://github.com/idr4n/github-monochrome.nvim): GitHub-inspired monochrome color scheme.
- [SupaTheme](https://github.com/brandsoy/SupaTheme): Supa color scheme.
- [rwth.nvim](https://github.com/mryodo/rwth.nvim): RWTH-inspired color scheme.

## Editing And Navigation

- [mini.nvim](https://github.com/echasnovski/mini.nvim): Modular utilities for text editing, icons, notifications, and buffers.
- [which-key.nvim](https://github.com/folke/which-key.nvim): Displays available keybindings as you type.
- [nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons): File-type icons for Neovim interfaces.
- [fzf-lua](https://github.com/ibhagwan/fzf-lua): Fast fuzzy finder for files, buffers, search, and more.
- [yazi.nvim](https://github.com/mikavilpas/yazi.nvim): Integrates the Yazi terminal file manager.
- [nvim-tree.lua](https://github.com/nvim-tree/nvim-tree.lua): File-system tree and workspace navigation.

## Git

- [gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim): Shows Git changes and provides buffer-level Git actions.
- [diffview.nvim](https://github.com/sindrets/diffview.nvim): Side-by-side Git diffs and file history views.

## LSP And Code Quality

- [blink.cmp](https://github.com/Saghen/blink.cmp): Fast completion engine for Neovim.
- [nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter): Parser-based syntax highlighting and code understanding.
- [nvim-lspconfig](https://github.com/neovim/nvim-lspconfig): Ready-to-use configurations for language servers.
- [mason.nvim](https://github.com/williamboman/mason.nvim): Installs and manages external developer tools.
- [mason-lspconfig.nvim](https://github.com/williamboman/mason-lspconfig.nvim): Bridges Mason with LSP server configuration.
- [mason-tool-installer.nvim](https://github.com/WhoIsSethDaniel/mason-tool-installer.nvim): Automatically installs configured Mason tools.
- [conform.nvim](https://github.com/stevearc/conform.nvim): Lightweight formatter runner.
- [nvim-lint](https://github.com/mfussenegger/nvim-lint): Asynchronous linting framework.
- [SchemaStore.nvim](https://github.com/b0o/SchemaStore.nvim): JSON schemas for improved configuration-file editing.
- [roslyn.nvim](https://github.com/seblyng/roslyn.nvim): Roslyn language-server integration for C#.

## Markdown And Media

- [markdown-preview.nvim](https://github.com/iamcco/markdown-preview.nvim): Live browser preview for Markdown files.
- [render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim): Renders Markdown syntax directly in Neovim buffers.
- [image.nvim](https://github.com/3rd/image.nvim): Displays images inside supported Neovim environments.
- [templ.vim](https://github.com/joerdav/templ.vim): Syntax support for Templ files.
- [nvim-colorizer.lua](https://github.com/norcalli/nvim-colorizer.lua): Highlights color codes with their actual colors.

## AI And Utilities

- [copilot.lua](https://github.com/zbirenbaum/copilot.lua): GitHub Copilot completion integration.
- [dooing](https://github.com/atiladefreitas/dooing): In-editor task and to-do list management.
